02 / The Core Idea

Challenge-Based Learning, not doomscrolling

  • —Every 5 videos, a non-dismissible Trivia Rush quiz interrupts the feed
  • —Questions are tagged to match the clip the viewer just watched
  • —The app doesn't slow the feed down — it makes continuing to scroll conditional on proving retention
  • —A direct structural check against pure engagement-driven scrolling

03 / Tech Stack

Tech Stack

Client

  • Flutter, targeting Android, iOS, macOS, Windows, Linux, Web
  • State managed via flutter_riverpod
  • JWT persisted with shared_preferences
  • Cross-platform YouTube embed via flutter_inappwebview (native) and the web package (browser)

Backend

  • FastAPI + SQLAlchemy
  • SQLite by default, switches to Postgres via DATABASE_URL env var
  • Trivia generation falls back to the Gemini API when no tagged question matches

Embedded backend

  • A second, hand-maintained Kotlin server inside the Android app
  • Mirrors the Python API, with a bundled SQLite asset DB for fully offline use

Deploy / CI

  • Fly.io hosting via fly.toml
  • GitHub Actions builds macOS and Windows desktop release bundles on tag push

05 / Production Tradeoffs

Production Tradeoffs (Made Deliberately)

Three tradeoffs, each with a stated upgrade path already sketched in the codebase

In-memory rate limiting (5/min on login+signup, 20/min on guest auth)→Redis
SQLite as the default store→Postgres; switch commands already commented into fly.toml
Wide-open CORS for local dev→An origin allowlist

Schema discrepancy note: the root-level schema.sql is a stale, aspirational Postgres+Supabase design and does not match what's running. The live schema is backend/app/models.py (SQLAlchemy, integer primary keys, SQLite types).

08 / Backend API Surface

Backend API Surface

Four routers, mounted in main.py

POST/auth/signup, /auth/login — rate-limited, 5/min
GET/POST/videos/{id}/comments
POST/auth/guest — rate-limited, 20/min
GET/trivia/random — matches via topic_keywords, falls back to Gemini
GET/videos — paginated, kind=short|long|all
POST/trivia/{question_id}/submit
GET/videos/search — ?q= across title/channel/tags/description
POST/GET/progress/sync, /progress/me
POST/GET/videos/{id}/like, /like-status
GET/progress/stats — streaks, accuracy over time, per-topic mastery
